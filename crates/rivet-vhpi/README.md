# rivet-vhpi

The VHPI backend. Verified on NVC 1.23; carries cocotb's catalogued quirks
for Questa, Riviera and Xcelium VHDL, which have never run.

Part of [Rivet](https://github.com/A-Ravioli/rivet), a Rust harness for
hardware verification that replaces cocotb.
