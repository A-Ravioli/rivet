# Rivet

The user-facing crate: `#[rivet::test]`, triggers, handles, and the prelude. Depend on this one.

Part of [Rivet](https://github.com/A-Ravioli/rivet), a Rust harness for
hardware verification that replaces cocotb. Start with the
[book](https://github.com/A-Ravioli/rivet/tree/main/docs/book) and the
[quickstart](https://github.com/A-Ravioli/rivet#quickstart).
